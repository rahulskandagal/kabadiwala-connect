2-minute demo

  1. Price tab → tap a sample photo (or take one) → AI suggests the material → 🔊 hear the price → set weight → Save.
  2. Recyclers tab → Use my location → best match → Book pickup.
  3. Choose Cash or UPI → Create handover & OTP → OTP + QR receipt (GPS-stamped, hash-chained).
  4. Console (top-right) → select the recycler → enter the OTP → Confirm → Mark paid.
  5. Back in the app → Earnings shows the paid deal → download the CSV statement.
  6. Turn on airplane mode and reload — it still works.

Language switch (हिंदी / मराठी / English) is at the top-right of the app. Voice needs a Hindi/Marathi TTS voice on the phone (Android has them built in).
